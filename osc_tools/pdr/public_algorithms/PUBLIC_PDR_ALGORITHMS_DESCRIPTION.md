# Подробное математическое описание 4 физических алгоритмов РНМ (PDR)

**Дата последнего обновления:** 09.08.2026
**Модуль:** `osc_tools/pdr/public_algorithms/`  
**Назначение:** Описание 4 открытых алгоритмов направления мощности, сгруппированных по фундаментальным физическим принципам измерительных органов.

---

## 1. Единый стандарт логики сигналов, памяти, уставок и диагностики

### 1.1. Состояния решения БАВР
- **`FORWARD` (1 / БЛОКИРОВКА БАВР)**: Мощность течёт из сети в нагрузку ($P > 0$, КЗ на шинах / нормальный режим) $\implies$ `is_tripped = True` (блокировка БАВР включена, переключение на резерв запрещено!).
- **`REVERSE` (0 / РАЗРЕШЕНИЕ БАВР)**: Мощность течёт из шин подстанции в сеть ($P < 0$, выбег двигателей / КЗ во внешней сети) $\implies$ `is_tripped = False` (блокировка БАВР снята, переключение на резерв разрешено!).

### 1.2. Ограничение диагностического словаря при сохранения датасетов
> **ВАЖНОЕ ПРИМЕЧАНИЕ ПО ПАМЯТИ И РАЗМЕТКЕ:**  
> Поле `diagnostics` (`forward_count`, `voltage_mode`, `phase_results`) генерируется алгоритмами исключительно для локальной отладки и единичного логирования ошибок.  
> При массовой генерации разметки в файлах `.npz` датасетов сохранются только компактные плотные массивы:
> - `directions` (int16 массив меток на весь файл);
> - `margins` (float32 массив непрерывных запасов срабатывания);
> - `confidences` (float32 массив уверенности);
> - `warmup_mask` (bool массив отсутствия обязательной истории teacher).

### 1.3. Расчёт уставок по умолчанию (после первой физической нормировки)
- **Угол максимальной чувствительности (УМЧ / RCA)**: $\varphi_{mch\_deg} = 45.0^\circ$ (ток отстаёт от напряжения на $45^\circ$);
- **`i_min_pu = 0.05` о.е.** ($0.25\text{ А}$ при $I_{nom}=5\text{ А}$ или $0.05\text{ А}$ при $I_{nom}=1\text{ А}$);
- **`u_min_pu = 0.05` о.е.** (порог переключения на память $U_{mem}$);
- **`p_thresh_pu = 0.05` в физической RMS p.u.-координате** — общая уставка
  двух публичных мощностных органов, соответствующая $U_{nom}\cdot0.05I_{nom}$.
  При разметке Phase 5 профиль `dataset_peak_phasor` переводит её во внутреннее
  значение $0.00096225$ с учётом делителей 20 и 3, фазного базиса и peak DFT.

### 1.4. Достаточность и восстановление сигналов

Все четыре органа требуют не менее двух фазных токов и двух фазных либо линейных
напряжений. Третьи величины восстанавливаются до расчёта. Если это невозможно,
результат `UNLABELED`. Пофазные органы применяют AND строго ко всем трём
восстановленным фазам. Расчёт прямой последовательности из линейных напряжений
выполняется через их эквивалентное фазное представление, что сохраняет комплексную
эквивалентность фазного и линейного входов.

## 2. Спецификация 4 физических алгоритмов РНМ

### 2.1. Пофазный угловой алгоритм РНМ (`phase_pdr_basic`)
- **ID:** `phase_pdr_basic` | **Файл:** `basic_phase.py` | **Класс:** `PhasePDRAlgorithm`
- **Физический принцип:** Анализ углов сдвига по каждой из 3 восстановленных фаз с пофазным объединением «И» (AND).
- **Поляризация:** Поддерживает `quadrature_90` ($I_A \leftrightarrow U_{BC}$ со сдвигом 90°) и `direct` ($I_A \leftrightarrow U_A$).
- **Уставки:** `phi_mch_deg` = 45.0°, `u_min_pu` = 0.05, `i_min_pu` = 0.05, `sector_width_deg` = 180.0°.

---

### 2.2. Угловой алгоритм прямой последовательности (`pos_seq_pdr_basic`)
- **ID:** `pos_seq_pdr_basic` | **Файл:** `basic_pos_seq.py` | **Класс:** `PositiveSequencePDRAlgorithm`
- **Физический принцип:** Угловая секторная оценка по симметричным составляющим прямой последовательности $U_1, I_1$. Поддерживает работу от любых двух фазных либо любых двух линейных напряжений с восстановлением третьей величины.
- **Уставки:** `phi_mch_deg` = 45.0°, `u_min_pu` = 0.05, `i_min_pu` = 0.05, `sector_width_deg` = 180.0°.

---

### 2.3. Пофазный алгоритм активной мощности 90° схемы (`phase_power_pdr_basic`)
- **ID:** `phase_power_pdr_basic` | **Файл:** `basic_phase_power.py` | **Класс:** `PhasePowerPDRAlgorithm`
- **Физический принцип:** Пофазный расчёт мощностного момента 90° схемы по всем 3 фазам с объединением по правилу «И» (AND):
  $$T_{op\_A} = \frac{|\mathbf{U}_{BC}|}{\sqrt{3}} |\mathbf{I}_A| \cos(\arg \mathbf{U}_{BC} - \arg \mathbf{I}_A - \varphi_{mch\_90})$$
  где $\varphi_{mch\_90} = 45^\circ - 90^\circ = -45.0^\circ$.
- **Уставки:** `phi_mch_deg` = 45.0°, `i_min_pu` = 0.05, `u_min_pu` = 0.05,
  `p_thresh_pu` = 0.05 physical RMS p.u. Деление $U_{line}$ на $\sqrt{3}$ обеспечивает тот же
  масштаб момента, что у $U_1 I_1$, поэтому используется одна уставка мощности.
- **Сопоставление с устройствами:** БМРЗ-БАВР-01 / БМРЗ-БАВР-56 (НТЦ «Механотроника»).

---

### 2.4. Алгоритм мощности прямой последовательности (`pos_seq_power_pdr_basic`)
- **ID:** `pos_seq_power_pdr_basic` | **Файл:** `basic_pos_seq_power.py` | **Класс:** `PositiveSequencePowerPDRAlgorithm`
- **Физический принцип:** Мощностной момент прямой последовательности $P_1 = \text{Re}\left[ \mathbf{V}_1 \cdot \left( \mathbf{I}_1 \cdot e^{+j MTA} \right)^* \right]$ для принятой конвенции $\arg U-\arg I=MTA$.
- **Уставки:** `mta_deg` = 45.0°, `u_min_pu` = 0.05, `i_min_pu` = 0.05, `p_thresh_pu` = 0.05 в физической RMS p.u.-координате.
- **Пороговая логика:** сначала проверяются `i_min_pu` и `u_min_pu`, затем
  прямое направление подтверждается условием `T_op >= p_thresh_pu`, а запас
  равен `T_op - p_thresh_pu`. Обратная либо недостаточная по рабочей мощности
  проекция даёт `REVERSE` в двухсостоянийном контракте.
- **Сопоставление с устройствами:** SEL-351 / SEL-751 (функция 32P), ЭКРА 217 БАВР ($P_1 < -P_{thresh}$), ABB Relion (DOPPDPR 32R).
