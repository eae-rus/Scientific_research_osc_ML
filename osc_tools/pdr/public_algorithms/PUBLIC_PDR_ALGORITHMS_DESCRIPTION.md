# Подробное математическое описание публичных алгоритмов РНМ (PDR)

**Дата:** 24.07.2026  
**Модуль:** `osc_tools/pdr/public_algorithms/`  
**Назначение:** Описание открытых базовых алгоритмов направления мощности для проверки корректности работы и математических формул.

---

## 1. Базовый фазный алгоритм РНМ (`PhasePDRAlgorithm`)

- **Идентификатор:** `phase_pdr_basic`
- **Файл:** `osc_tools/pdr/public_algorithms/basic_phase.py`
- **Класс:** `PhasePDRAlgorithm`
- **Применение:** Пофазная оценка направления мощности с логикой «И» (AND) для объединения решений фаз.

### Конфигурируемые уставки (`tunable_parameters`):

| Уставка | Тип | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `phi_mch_deg` | `float` | `45.0` | Угол максимальной чувствительности $\varphi_{mch}$ в градусах (ток отстает от U) |
| `u_min_pu` | `float` | `0.05` | Минимальный порог чувствительности по напряжению в о.е. |
| `i_min_pu` | `float` | `0.02` | Минимальный порог чувствительности по току в о.е. |
| `sector_width_deg` | `float` | `180.0` | Ширина сектора срабатывания $\theta_{sec}$ в градусах (полусектор $\Delta = 90^\circ$) |

### Математический алгоритм расчёта:

1. **Проверка входных сигналов по каждой фазе $k \in \{A, B, C\}$**:
   - Извлекаются комплексные фазоры $U_k$ и $I_k$.
   - Вычисляются амплитуды: $|U_k| = |U_k|$, $|I_k| = |I_k|$.
   - Если $|U_k| < U_{min}$ или $|I_k| < I_{min}$ (или сигнал отсутствует/содержит NaN), результат фазы $k$ помечается как `REVERSE` (0).

2. **Вычисление углов и отклонений**:
   - Угол напряжения: $\varphi_{U_k} = \text{atan2d}(\Im(U_k), \Re(U_k))$
   - Угол тока: $\varphi_{I_k} = \text{atan2d}(\Im(I_k), \Re(I_k))$
   - Фазовый сдвиг между напряжением и током:
     $$\varphi_k = \text{wrap180}\left( \varphi_{U_k} - \varphi_{I_k} \right)$$
   - Отклонение от угла максимальной чувствительности:
     $$\Delta \varphi_k = \text{wrap180}\left( \varphi_k - \varphi_{mch} \right)$$

3. **Критерий срабатывания фазы**:
   $$\text{Phase\_Dir}_k = \begin{cases} \text{FORWARD (1)}, & \text{если } |\Delta \varphi_k| \le \frac{\theta_{sec}}{2} \\ \text{REVERSE (0)}, & \text{иначе} \end{cases}$$

4. **Угловой запас фазы (Margin)**:
   $$\text{margin}_k = \frac{\theta_{sec}}{2} - |\Delta \varphi_k|$$

5. **Логика «И» (AND) для пофазного объединения**:
   - Итоговый сигнал органа `FORWARD` (1) формируется **только если все 3 измеренные/доступные фазы** одновременно зафиксировали прямое направление (`forward_count == valid_phase_count`).
   - Если хотя бы в одной фазе зафиксировано `REVERSE` (0) или малый сигнал, общий выход органа — `REVERSE` (0).

## 2. Базовый алгоритм РНМ прямой последовательности (`PositiveSequencePDRAlgorithm`)

- **Идентификатор:** `pos_seq_pdr_basic`
- **Файл:** `osc_tools/pdr/public_algorithms/basic_pos_seq.py`
- **Класс:** `PositiveSequencePDRAlgorithm`
- **Применение:** Оценка направления мощности по симметричным составляющим прямой последовательности первой гармоники ($U_1, I_1$).

### Конфигурируемые уставки (`tunable_parameters`):

| Уставка | Тип | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `phi_mch_deg` | `float` | `45.0` | Угол максимальной чувствительности $\varphi_{mch}$ в градусах |
| `u1_min_pu` | `float` | `0.05` | Порог по напряжению прямой последовательности в о.е. |
| `i1_min_pu` | `float` | `0.02` | Порог по току прямой последовательности в о.е. |
| `sector_width_deg` | `float` | `180.0` | Ширина сектора срабатывания $\theta_{sec}$ в градусах (полусектор $\Delta = 90^\circ$) |

### Математический алгоритм расчёта:

1. **Вычисление фазоров прямой последовательности**:
   $$U_1 = \frac{1}{3} \left( U_A + a \cdot U_B + a^2 \cdot U_C \right)$$
   $$I_1 = \frac{1}{3} \left( I_A + a \cdot I_B + a^2 \cdot I_C \right)$$
   где $a = -0.5 + j \frac{\sqrt{3}}{2}$ (комплексный поворот на $+120^\circ$).

2. **Проверка порогов чувствительности**:
   - Если $|U_1| < U_{1\_min}$ или $|I_1| < I_{1\_min}$ (или хотя бы одна фаза отсутствует), выход органа — `REVERSE` (0).

3. **Вычисление углов и фазового сдвига**:
   - Угол напряжения: $\varphi_{U_1} = \text{atan2d}(\Im(U_1), \Re(U_1))$
   - Угол тока: $\varphi_{I_1} = \text{atan2d}(\Im(I_1), \Re(I_1))$
   - Угол прямой последовательности:
     $$\varphi_1 = \text{wrap180}\left( \varphi_{U_1} - \varphi_{I_1} \right)$$
   - Отклонение от угла чувствительности:
     $$\Delta \varphi_1 = \text{wrap180}\left( \varphi_1 - \varphi_{mch} \right)$$

4. **Критерий срабатывания (FORWARD=1)**:
   $$\text{Direction} = \begin{cases} \text{FORWARD (1)}, & \text{если } |\Delta \varphi_1| \le \frac{\theta_{sec}}{2} \\ \text{REVERSE (0)}, & \text{иначе} \end{cases}$$

5. **Угловой запас (Margin)**:
   $$\text{margin} = \frac{\theta_{sec}}{2} - |\Delta \varphi_1|$$
