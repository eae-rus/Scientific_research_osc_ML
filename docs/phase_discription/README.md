Фазу 6 читать с [плана действий](phase_6/PHASE_6_RESEARCH_PLAN.md). [Инструкция](phase_6/PHASE_6_EXTRACTION_PROMPT_DRAFT.md) задаёт правила чтения и единые 12 разделов отчёта. [Словарь](phase_6/PHASE_6_TERMINOLOGY_DRAFT.md) хранится отдельно и подключается при запуске. [Наблюдения](phase_6/PHASE_6_RESEARCH_NOTES.md) сохраняют разбор примеров, не перегружая план. Четыре согласованных образца — в [reports](phase_6/reports/). Для следующего запуска подготовлена [инструкция независимого повторного прохода](phase_6/PHASE_6_INDEPENDENT_RUN_PROMPT.md): прежние образцы читаются только после фиксации новых отчётов.

Разделение на четыре роли учитывает новые примечания автора: план должен быть порядком действий, словарь — отдельным документом. Параллельные планы и повторяющиеся перечни рисков не создаются. Точные снимки прежних текстов и комментариев находятся в закрытом рабочем аудите `private/phase6_review/2026-10-08-future/`: `consolidation_snapshot.json` и `oct09_phase6_review.json`. Исторические инвентаризации могут содержать прежние пути; рабочие ссылки обновляются при изменении структуры.
