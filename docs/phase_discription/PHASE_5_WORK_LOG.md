## 24.07.2026 — Полномасштабное ревью и доработка адаптивного органа РНМ (БАВР)

- **Результаты глубокого ревью кода РНМ**:
  - Проведено сопоставление реализованной Python-версии с эталонным C-кодом прошивки БАВР `PDRF.c` из проекта `mir`.

- **Полная адаптивность прямой последовательности** (`private/pdr_algorithms/adaptive_pdr.py`):
  - Режим прямой последовательности (`rnm_type = "positive"`) выставлен в качестве основного режима по умолчанию для БАВР.
  - В метод `_compute_positive` полностью внедрены 3 типа адаптивностей по фазорам прямой последовательности $U_1, I_1$:
