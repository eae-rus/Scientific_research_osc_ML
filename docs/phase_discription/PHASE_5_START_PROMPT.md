## Научная цель и текущий статус (Этап 7: РНМ / PDR)

Phase 5 объединяет физически обоснованный KAN-Transformer с измерительными органами Реле направления мощности (РНМ / PDR) для БАВР:
1. **Инфраструктура РНМ (`osc_tools/pdr/`)**:
   - Реализована генерация псевдоразметки по 10-периодному скользящему окну (`PDRDatasetLabeler`).
   - Настроена зона разогрева (`UNLABELED = -999`) для первых 10 периодов.
   - Кодирование направлений: `FORWARD = 1` (прямое / разрешение БАВР), `REVERSE = 0` (обратное / блокировка БАВР).
   - Пофазный анализ использует строгую логику **«И» (AND)**: орган даёт `FORWARD` только если все 3 измеренные фазы показывают прямое направление.
2. **Адаптивный алгоритм БАВР (`private/pdr_algorithms/adaptive_pdr.py`)**:
   - Реализован на чистом Python по материалам прошивки терминала БАВР (`mir` / `PDRF.c`).
   - Работает по умолчанию на прямой последовательности (`rnm_type = "positive"`).
   - Включает 3 типа адаптивностей: коррекция угла чувствительности $\varphi_{mch}$ по предыстории за 10 периодов, динамический угол зоны срабатывания $\alpha$, и адаптивный порог по току $I_{abs}$.
3. **Исследование сторонних производителей**:
   - Создан бренд-нейтральный промпт и ТЗ в `docs/phase_discription/PDR_MANUFACTURERS_RESEARCH_BRIEF.md` для запуска веб-агента (SEL, Siemens SIPROTEC, ABB Relion, Schneider, ЭКРА).
4. **Тестирование**:
   - Все 563 unit- и интеграционных теста успешно проходят (100% PASS).
   - Публичные CI/CD защищены хуком `test_private_pdr_hooks.py` (при отсутствии `private/` приватные тесты безопасны пропускаются).
