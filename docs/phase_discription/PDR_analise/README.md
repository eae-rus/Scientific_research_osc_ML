# Отчёты по РНМ: что читать

Эта папка содержит материалы разного статуса. Номер файла означает порядок
появления, а не одинаковую степень актуальности.

## Актуальные отчёты выполненных опытов

- `Report_6_expert_v1.md` — первый импортированный экспертный слой и его аудит;
- `Report_7_training_pilot_v1.md` — первый weak→expert пилот и объяснение
  предварительной точности 100%;
- `Report_8_phase5_status_and_training_coverage.md` — наиболее свежий статус
  фазы, исправленный охват weak-обучения и полный контур validation.

Если нужен текущий статус, начинать следует с отчёта 8. Отчёты 6 и 7 нужны как
воспроизводимый протокол конкретных ранних опытов и не заменяют свежую сводку.

## Исторические литературные материалы

`archive_literature/Report_1.md` — `archive_literature/Report_5.md` являются
ранними обзорами литературы и
производителей. Они частично дублируют друг друга, неоднородны по стилю и не
являются нормативным описанием реализованной математики. Их нельзя использовать
как источник актуальных уставок или формул без повторной проверки.

Файлы убраны в `archive_literature`, но сохраняются как исходный
исследовательский материал: их
возможные ссылки и идеи ещё могут пригодиться при подготовке статьи. После
проверки источников разумно объединить полезные фрагменты в один литературный
обзор и только затем удалить дубликаты. Автоматически удалять их сейчас нельзя.

## Где находятся правила и планы

- эксплуатационная инструкция — `../PHASE_5_PDR_PIPELINE_GUIDE.md`;
- математика реализованных органов — `../PHASE_5_PDR_ALGORITHMS.md`;
- план статистических исследований — `../PHASE_5_STATISTICAL_RESEARCH_PLAN.md`;
- общий план всей фазы — `../PHASE_5_PLAN.md`;
- хронология изменений — `../PHASE_5_WORK_LOG.md`.

Новый отчёт создаётся только для зафиксированного опыта с самостоятельными
входами и выводами. Операционные инструкции, временные заметки и повтор
содержимого плана сюда не добавляются.
