# Спецификация и архитектура алгоритмов РНМ (PDR) в Phase 5

Дата создания: **24.07.2026**  
Модуль: `osc_tools/pdr/`

## 1. Назначение и научные рамки

Реле направления мощности (РНМ, англ. Power Directional Relay — PDR) выступает основным прикладным измерительным органом для исследования возможностей Physical KAN-Transformer на реальных осциллограммах.

Основная задача нейросетевого органа: по 200 мс (10 периодов сети) спектральной предыстории токов и напряжений принимать детерминированное физически обоснованное решение о направлении мощности в текущей конечной точке.

## 3. Контракты данных и кодирование направлений

### Перечисление `PDRDirection`:
- `UNLABELED (-999)`: Неразмеченная область (первые 10 периодов разогрева / недостаток предыстории). Позволяет однозначно отличать отсутствие разметки от нулевого сигнала РНМ.
- `REVERSE (-1)`: Обратное направление мощности (КЗ за спиной / блокировка).
- `BLOCK (0)`: Блокировка (величины токов/напряжений ниже порогов чувствительности).
- `FORWARD (1)`: Прямое направление мощности (КЗ в зоне действия / срабатывание).

## 4. Публичные открытые алгоритмы

### 4.1. Базовый фазный алгоритм (`phase_pdr_basic`)
- **Параметры**:
  - `phi_mch_deg`: $45.0^\circ$ (угол максимальной чувствительности, ток отстает от напряжения).
  - `u_min_pu`: $0.05$ о.е. (порог чувствительности по напряжению).
  - `i_min_pu`: $0.02$ о.е. (порог чувствительности по току).
  - `sector_width_deg`: $180.0^\circ$ (ширина зоны срабатывания $\pm 90^\circ$ от $\phi_{mch}$).
- **Принцип**: Вычисляется пофазный сдвиг $\varphi_k = \arg(U_k) - \arg(I_k)$. Направление FORWARD устанавливается при попадании угла $\varphi_k$ в зону срабатывания.

### 4.2. Базовый алгоритм прямой последовательности (`pos_seq_pdr_basic`)
- **Параметры**: Аналогичные уставки относительных величин (`u1_min_pu`, `i1_min_pu`, `phi_mch_deg` $= 45^\circ$).
- **Принцип**: Вычисляются фазоры прямой последовательности первой гармоники $U_1, I_1$ и угол $\varphi_1 = \arg(U_1) - \arg(I_1)$.

### 4.3. Заглушки алгоритмов сторонних БАВР
- `bavr_manufacturer_power_stub`: Каркас для добавления алгоритмов направления по мощности.
- `bavr_manufacturer_current_stub`: Каркас для токовых алгоритмов РНМ сторонних производителей.

## 5. Добавление закрытых алгоритмов (mir/MIRAPS)

Для подключения проприетарного алгоритма из проектов `mir`/`MIRAPS`:
1. Поместите модуль с реализацией в каталог `private/pdr_algorithms/my_algorithm.py`.
2. Унаследуйте класс от `PDRAlgorithm`.
3. Зарегистрируйте класс через декоратор `@PDRRegistry.register`.
4. При отсутствии закрытой папки система автоматически вернёт `PlaceholderPDRAlgorithm` с понятным предупреждением в логах без прерывания работы публичного кода.
