## 1. Назначение и научные рамки

Реле направления мощности (РНМ, англ. Power Directional Relay — PDR) выступает основным прикладным измерительным органом для исследования возможностей Physical KAN-Transformer на реальных осциллограммах.

Основная задача нейросетевого органа: по спектральной предыстории токов и напряжений принимать детерминированное физически обоснованное решение о направлении мощности в текущей точке.

## 3. Контракты данных и кодирование направлений

### Перечисление `PDRDirection`:
- `UNLABELED (-999)`: Неразмеченная или невалидная область (зона начального разогрева БПФ или отсутствие входных сигналов).
- `REVERSE (0)`: РАЗРЕШЕНИЕ БАВР (мощность в сеть / $P < 0$ / выбег двигателей / КЗ во внешней сети) $\implies$ `is_tripped = False`.
- `FORWARD (1)`: БЛОКИРОВКА БАВР (мощность в нагрузку / $P > 0$ / нормальный режим / КЗ на шинах) $\implies$ `is_tripped = True`.

## 4. Публичные открытые физические алгоритмы

Подробное математическое описание 4 физических алгоритмов с формулами и уставками приведено в документе: [PUBLIC_PDR_ALGORITHMS_DESCRIPTION.md](file:///d:/Программирование/Fork/Scientific_research_osc_ML/osc_tools/pdr/public_algorithms/PUBLIC_PDR_ALGORITHMS_DESCRIPTION.md).

### Краткий обзор:
1. **Пофазный угловой алгоритм (`phase_pdr_basic`)**:
   - Реализован в `basic_phase.py`. Пофазный расчёт углов $\varphi_k = \arg(U_k) - \arg(I_k)$ с объединением по условию «И» (AND).
2. **Угловой алгоритм прямой последовательности (`pos_seq_pdr_basic`)**:
   - Реализован в `basic_pos_seq.py`. Секторная оценка по симметричным составляющим $U_1, I_1$ с поддержкой любой пары 2 линейных напряжений.
3. **Пофазный алгоритм активной мощности 90° схемы (`phase_power_pdr_basic`)**:
   - Реализован в `basic_phase_power.py`. Пофазный мощностной момент по 90° схеме (Механотроника БМРЗ-БАВР-01).
4. **Алгоритм активной мощности прямой последовательности (`pos_seq_power_pdr_basic`)**:
   - Реализован в `basic_pos_seq_power.py`. Активная мощность / Torque Equation прямой последовательности (SEL 32P, ЭКРА 217 БАВР).

## 5. Закрытый адаптивный алгоритм (mir/MIRAPS)

- Реализован в `private/pdr_algorithms/adaptive_pdr.py`.
- Работает по умолчанию на прямой последовательности (`rnm_type = "positive"`).
- Содержит 3 вида адаптивностей: по углу нагрузки предыстории ($\varphi_{mch\_eff}$), по сужению зоны ($\alpha_{pos}, \alpha_{neg}$) и по модулю тока предыстории ($I_{abs\_thresh}$).

**Примечание автора**: Описан исследуемый алгоритм, при необходимости могут быть заменены на другие, без подробного описания логики работы.
