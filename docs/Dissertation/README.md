## Где что хранить

| Папка | Назначение |
|---|---|
| `Архивное/` | Уже существующие исходные DOCX и PDF, сохраняются без изменений |
| `planning/` | План, карта источников, решения и контрольные сведения |
| `migration/` | Точная исходная копия, затем результаты технического переноса и сверки |
| `manuscript/` | Рабочий текст в LaTeX и актуальный PDF; при правке учитывать результаты аудита |
| `review/` | Замечания, история их рассмотрения и результаты сверки |
| `tools/` | Вспомогательные скрипты работы с документацией |

Используем Git текущего проекта; вложенный репозиторий не создаём. Планируем фиксировать технический перенос отдельно от научной правки. Коммиты в рамках подготовки не выполнялись. Git не заменяет отдельную резервную копию.
