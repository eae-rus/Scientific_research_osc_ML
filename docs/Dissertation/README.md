# Работа над диссертацией

Тема из титульного листа v0.5: «Совершенствование алгоритмов быстродействующего автоматического ввода резерва с применением методов машинного обучения». Название сохраняем.

Сейчас подготовлена организация работы. Перенос текста в LaTeX и объединение со статьями ещё не начаты. Исходные документы не редактировались.

- [Инструкция исполнителю](planning/EXECUTION_GUIDE.md) — как брать одну задачу, проверять результат и передавать работу.

- [Стартовый промпт](planning/START_PROMPT.md) — короткое поручение следующему исполнителю.
- [Карта материалов](planning/SOURCE_MAP.md) — найденные источники и их предполагаемая роль.

## Где что хранить

| Папка | Назначение |
|---|---|
| `Архивное/` | Уже существующие исходные DOCX и PDF, сохраняются без изменений |
| `planning/` | План, карта источников, решения и контрольные сведения |
| `migration/` | Точная исходная копия, затем результаты технического переноса и сверки |
| `manuscript/` | Будущий единый редактируемый текст в LaTeX; пока только описание структуры |
| `review/` | Замечания, история их рассмотрения и результаты сверки |
| `tools/` | Вспомогательные скрипты работы с документацией |

Используем Git текущего проекта; вложенный репозиторий не создаём. Планируем фиксировать технический перенос отдельно от научной правки. Коммиты в рамках подготовки не выполнялись. Git не заменяет отдельную резервную копию.

Следующий шаг — **A01: проверка исходной точки**. Затем идут реестры текста, объектов и замечаний, техническая проба и полный перенос. Статьи добавляются после приёмки переноса. Детализация плана не означает выполнения этих задач: сейчас подготовлены инструкции, исходная диссертация остаётся без изменений.
