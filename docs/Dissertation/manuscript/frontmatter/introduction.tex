\noindent\textbf{НАПИСАТЬ ВВЕДЕНИЕ!}\par\vspace{0.3cm}
% DISS-005-B0117
\par\vspace{0.3cm}
% DISS-005-B0118
\noindent\textbf{Основная цель диссертации\commentnote{DISS-005-C0003}{Алексей Евдаков [2]}{Вставлен для того, чтобы было удобнее соблюдать общую идею и применять нейронки для правок}\commentnote{DISS-005-C0004}{Алексей Евдаков [2] (ответ на C0003)}{Повторюсь, это прост краткий обзор, того что уже есть}:}\par\vspace{0.2cm}
% DISS-005-B0119
Разработка и исследование методов и алгоритмов для повышения надежности, быстродействия и адаптивности систем быстродействующего автоматического ввода резерва (БАВР), в частности, за счет совершенствования работы реле направления мощности (РНМ) и алгоритмов восстановления нормального режима (ВНР), с использованием обширного анализа реальных осциллограмм и применения современных подходов, включая машинное обучение.\par\vspace{0.2cm}
% DISS-005-B0120
\par\vspace{0.3cm}
% DISS-005-B0121
\noindent\textbf{Ключевые проблемы, решаемые в диссертации (а в чём-то уже решённые):}\par\vspace{0.2cm}
% DISS-005-B0122
\begin{itemize}
  \item Недостаточная эффективность стандартных РНМ: Задержки срабатывания/отпускания, ложные блокировки РНМ в сложных режимах (внешние КЗ, пуск мощных двигателей, несимметричные нагрузки, колебания нагрузки, переходные процессы, насыщение ТТ).
% DISS-005-B0123
  \item Проблемы стандартных ВНР: Некорректные переключения при ОЗЗ, расхождении углов/частот между источниками, риски при одновременном срабатывании нескольких ВНР.
% DISS-005-B0124
  \item Ограничения традиционных методов анализа и проектирования РЗА: Сложность учета всего многообразия реальных режимов, трудоемкость ручной настройки, нехватка репрезентативных данных для верификации.
% DISS-005-B0125
  \item Необходимость адаптации РЗА к изменяющимся условиям сети: Интеграция распределенной генерации, усложнение конфигураций сети, разнообразие нагрузок.
% DISS-005-B0126
\end{itemize}
\par\vspace{0.3cm}
% DISS-005-B0127
\noindent\textbf{Структура и краткое содержание глав:}\par\vspace{0.2cm}
% DISS-005-B0128
\noindent\textbf{Глава 1: Современные проблемы быстродействующего автоматического ввода резерва и варианты их устранения стандартными методами}\par\vspace{0.2cm}
% DISS-005-B0129
Статус: Предварительный набросок, задающий общую проблематику.\par\vspace{0.2cm}
% DISS-005-B0130
\noindent\textbf{Содержание:}\par\vspace{0.2cm}
% DISS-005-B0131
Обоснование необходимости надежного электроснабжения и роли БАВР.\par\vspace{0.2cm}
% DISS-005-B0132
Сравнение БАВР и традиционного АВР, выделение преимуществ БАВР (быстродействие, селективность).\par\vspace{0.2cm}
% DISS-005-B0133
Описание базовых пусковых, разрешающих и блокирующих органов БАВР (контроль Umin, угол, частота, Umax, токовые защиты, РНМ, контроль U0 и др.).\par\vspace{0.2cm}
% DISS-005-B0134
Обозначение экономических и технологических преимуществ БАВР.\par\vspace{0.2cm}
% DISS-005-B0135
Ключевая проблема: Задержки и отказы БАВР, особенно из-за некорректной работы РНМ. Анализ влияния преобразования Фурье, математических особенностей расчета векторов, задержек при отсутствии двигательной нагрузки (обнуление сигналов за период сети).\par\vspace{0.2cm}
% DISS-005-B0136
Примеры реальных осциллограмм, демонстрирующие проблемы РНМ (долгий отпуск, блокировка через 200мс, отказ при несимметричном снижении напряжения).\par\vspace{0.2cm}
% DISS-005-B0137
Анализ существующих адаптивных функций РНМ (например, в терминалах ООО ''АПС'' версии 2.0) как частичного решения проблем.\par\vspace{0.2cm}
% DISS-005-B0138
Обзор и критика реализаций РНМ у различных производителей (ЭКРА, Механотроника (БМРЗ), Бреслер, ЧЭАЗ, Радиус Автоматика, Релематика, ABB, SEL, Siemens), с акцентом на то, что многие из них не решают фундаментальные проблемы РНМ.\par\vspace{0.2cm}
% DISS-005-B0139
Описание сложных случаев функционирования адаптивного РНМ: колебательный характер нагрузки (двигатели с частотным приводом), проблемы с выбором коэффициента отстройки (Котс) при пуске мощных синхронных двигателей, влияние внешних переключений на угол между секциями.\par\vspace{0.2cm}
% DISS-005-B0140
Введение в проблематику измерения тока с применением катушек Роговского и ёмкостных делителей как перспективной альтернативы традиционным ТТ и ТН, но с отсутствием на момент начала работы проработанных решений для БАВР.\par\vspace{0.2cm}
% DISS-005-B0141
Предварительные выводы о том, что стандартные и даже существующие адаптивные методы имеют ограничения, что требует более глубоких исследований и новых подходов.\par\vspace{0.2cm}
% DISS-005-B0142
\par\vspace{0.3cm}
% DISS-005-B0143
\noindent\textbf{Глава 2: Современные модернизации быстродействующего автоматического ввода резерва стандартными методами}\par\vspace{0.2cm}
% DISS-005-B0144
Статус: Первая стадия завершённости\par\vspace{0.2cm}
% DISS-005-B0145
\noindent\textbf{Содержание:}\par\vspace{0.2cm}
% DISS-005-B0146
\noindent\textbf{Углубленное исследование применения катушек Роговского (КР) для РНМ:}\par\vspace{0.2cm}
% DISS-005-B0147
\begin{itemize}
  \item Теоретическое сравнение КР и ТТ в идеальных условиях (анализ влияния апериодической составляющей, переходных процессов).
% DISS-005-B0148
  \item Оценка влияния различных факторов (постоянная времени затухания, начальный угол КЗ, частота дискретизации, высшие гармоники, оконные функции БПФ) на точность измерения.
% DISS-005-B0149
  \item Преимущества КР: отсутствие насыщения, более быстрый переход в установившийся режим, меньшее влияние апериодики.
% DISS-005-B0150
  \item Разработка гибридного алгоритма РНМ (комбинация сигналов от ТТ и КР) для улучшения работы в сложных режимах (удаленные КЗ, ОЗЗ с переходом в двухфазное, насыщение ТТ).
\end{itemize}
