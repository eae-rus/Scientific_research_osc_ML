# Рисунки диссертации

Действующие изображения размещаются в ch03, ch04 и ch05 по главам; shared предназначена для общих изображений при необходимости. Пути включения в TEX указываются явно. Новые и обновлённые рисунки сохранять сразу в папку соответствующей главы.

Предыдущие версии находятся в «_Устаревшее для памяти», также с разделением по главам. Существующие ch04_candidates содержат рабочие кандидаты главы 4.
