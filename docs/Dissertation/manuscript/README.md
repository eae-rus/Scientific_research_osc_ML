# Будущий текст диссертации

Текст ещё не перенесён. Этот каталог зарезервирован для единого LaTeX-источника после технической пробы.

Планируемые части: `main.tex`, `preamble.tex`, `frontmatter/`, `chapters/`, `backmatter/`, `appendices/`, `figures/`, `bibliography/references.bib`. Создавать их при переносе по реальной структуре v0.5. Новую композицию применять после приёмки точного переноса.

Файлы разбивать по устойчивым смысловым подразделам. Метки делать смысловыми (`sec:dataset-normalization`, `fig:pdr-pipeline`), не зависящими от номера главы. Сохранять таблицу соответствия старым номерам. В сгенерированный PDF не включать планы, реестры и служебные README.

Конкретный шаблон и сборочная команда пока не выбраны и не проверены. Эта папка не является готовым собирающимся проектом.
