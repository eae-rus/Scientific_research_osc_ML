# Реестры отображения и структуры документа (migration/mapping/)

В этой папке хранятся неизменяемые реестры структуры исходного документа `DISS-005` (`docs/Dissertation/Архивное/Диссертация (Евдаков А.Е.) v0.5.docx`), созданные в рамках задач **A03** и **A04**.

## Состав файлов

1. `blocks.json` — полный структурированный реестр всех 2307 блоков содержания исходного документа с неизменяемыми идентификаторами `block_id` (`DISS-005-B0001` .. `DISS-005-B2307`).
2. `source_outline.md` — реальное оглавление диссертации v0.5 со сквозными границами разделов, подразделов, черновых заметок и служебных частей (128 позиций).
3. `objects.json` — реестр всех 231 объектов документа (таблицы, формулы Office Math, внедрённые объекты OLE, рисунки и медиафайлы) с привязками к блокам, подписям, исходным локаторам, контрольным суммам и стратегиям переноса в LaTeX.
4. `references.json` — реестр всех 215 закладок, 82 гиперссылок, 303 полей Word (REF, PAGEREF, SEQ, STYLEREF) с разрешением связей, фиксацией 2 исходных неразрешённых ссылок и 103 текстовых ссылок на литературу.

## Схема базовой записи блока (`blocks.json`)

Каждый блок представляет собой атомарную структурную единицу текста (абзац `w:p` в основном тексте, оглавлении или ячейке таблицы):

```json
{
  "block_id": "DISS-005-B0001",
  "source_id": "DISS-005",
  "source_sha256": "50516d7832e6ea133d77b11b48802c4ed1929283ea7601134b878fab0e0338f7",
  "story_part": "word/document.xml",
  "locator": "/w:document/w:body/w:p[1]",
  "source_order": 1,
  "kind": "paragraph",
  "style_id": "Normal",
  "style_name": "Normal",
  "outline_level": null,
  "raw_text": "Текст абзаца...",
  "has_math": false,
  "has_drawing": false,
  "has_revisions": false,
  "comment_ids": [],
  "target_path": null,
  "target_label": null,
  "status": "unmapped"
}
```

## Правило обхода и предотвращения дублирования

- Обход документа выполняется по иерархии `w:document -> w:body` в естественном порядке чтения.
- Для прямых абзацев `w:body/w:p` создаётся отдельный блок.
- Для структурированных блоков `w:sdt` (оглавление) обходятся вложенные абзацы `w:sdtContent/w:p` с отметкой `kind: "toc_paragraph"`. Сам контейнер `w:sdt` текст не дублирует.
- Для таблиц `w:tbl` обходятся строки `w:tr` и ячейки `w:tc`, и каждый содержащийся в ячейке абзац `w:p` получает собственный блок с точным указанием позиции строки и столбца в `locator`. Текст всей таблицы целиком в отдельный текстовый блок не склеивается, что исключает задвоение текста.
- Нетекстовые служебные теги (`w:bookmarkEnd`, `w:sectPr`) не содержат текста и классифицируются как служебная разметка.
- Вспомогательные части пакета (`word/footnotes.xml`, `word/endnotes.xml`, `word/footer1.xml`) включены отдельными блоками с соответствующим `story_part`.
