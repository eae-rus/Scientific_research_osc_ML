# Технический перенос

`baseline/` хранит точную файловую копию выбранной архивной v0.5. DOCX не пересохраняется библиотекой и не редактируется. Проверка идентичности выполняется SHA-256; это подтверждает неизменность копии, а не качество вёрстки исходника.

При следующем этапе добавить `pilot/` для пробного переноса, `extracted/` для технического извлечения, `mapping/` для соответствия исходных блоков новым файлам, `checks/` для протоколов сверки. Полная конвертация пока не запускалась.

Исходный PDF находится в `../Архивное/`; соответствие DOCX ещё предстоит проверить. Альтернативный DOCX из `docs/article/` остаётся на месте и учтён отдельно.
