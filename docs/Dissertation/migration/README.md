# Технический перенос

`baseline/` хранит точную файловую копию выбранной архивной v0.5. DOCX не пересохраняется библиотекой и не редактируется. Проверка идентичности выполняется SHA-256; это подтверждает неизменность копии, а не качество вёрстки исходника.

Перенос выполнен: `pilot/` содержит пробу, `extracted/` — извлечённые материалы, `mapping/` — реестры, `checks/` — исторические протоколы. Аудит 21.09.2026 выявил неполные целевые привязки и недоработки приёмки; дальнейшие адресные исправления описаны в `../planning/RUNBOOK_REPAIR.md`. Не считать старые декларации 100% подтверждением ещё не выполненных повторных проверок.

Иcходный PDF находится в `../Архивное/`; соответствие DOCX ещё предстоит проверить. Альтернативный DOCX из `docs/article/` удалён автором 17.09.2026 для исключения дублирования.
