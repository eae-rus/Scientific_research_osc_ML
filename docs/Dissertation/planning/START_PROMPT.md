# Стартовый промпт исполнителю

Скопируйте абзац ниже целиком. Он поручает одну небольшую задачу. Для конкретной работы замените «первую доступную задачу» на её ID; для продолжительной сессии явно назовите нужный этап.

```text
Продолжи работу над диссертацией в docs/Dissertation. Прочитай AGENTS.md, planning/DECISIONS.md и planning/EXECUTION_GUIDE.md, затем возьми первую доступную задачу из planning/TASK_BOARD.md с завершёнными зависимостями. Прочитай её карточку и последний отчёт. Если задача повторяемая, выполни только одну конкретную дочернюю задачу; если детей ещё нет, сначала создай их по входному реестру. Выполни работу и все проверки карточки, сохраняя исходники, комментарии и научные ограничения. Не смешивай точный перенос с содержательной правкой и не придумывай недостающие сведения. Обнови очередь и planning/handoffs/<ID>.md: результат, доказательства проверок, ограничения и точный следующий шаг. DONE ставь только при выполнении всех критериев. Рутинные действия выполняй самостоятельно; при настоящем блокере сохрани сделанное и укажи, какого конкретно входа не хватает. В конце кратко сообщи ID, результат и следующий доступный ID.
```

В текущем состоянии первая задача — **A01**. Если очередь уже продвинулась, ориентироваться на неё, а не на эту стартовую подсказку.
