## OZZ-STATS

Вопрос: как распределены зарегистрированные кратности перенапряжения в подготовленном массиве ОЗЗ? Вход — 830 верифицированных записей DATA-OZZ, преимущественно кабельные сети 6–35 кВ. Для каждой записи рассчитан максимум напряжения неповреждённых фаз относительно **номинального фазного** напряжения (P0036–P0037). Независимая единица — запись только как заявленная единица анализа; группировка записей одного события/объекта не установлена.

Отбор наследует пороги и ручную верификацию DATA-OZZ, ограничения ТН/АЦП, смещение архива БАВР и исключение коммутационных бросков. Поэтому исследуется условное распределение измеренных значений после отбора, а не безусловное распределение всех ОЗЗ энергосистемы.

Методы: описательная таблица, KDE, эмпирическая CDF, box/violin plot (P0038–P0089). Параметр сглаживания и ядро KDE, определение «усов», способ интерполяции квантилей, sample/population ddof дисперсии, точные ID/скалярные значения, версия расчётного кода — `unknown`: в статье эти поля не раскрыты. Диапазон Q1–Q3 не является оценкой моды KDE. Близость среднего и медианы сама по себе не доказывает отсутствие выбросов: P0086 прямо отмечает их наличие.

Обучение, train/validation/test, выбор лучшей модели, размер окна нейросети и инференс — **не применимо**. Время измерительного окна/выделения зоны важно для определения максимума, но не задано в этой статье; не домысливать по позднему алгоритму репозитория. Статистическая проверка расхождения с теоретическим пределом, доверительные интервалы и групповой bootstrap здесь не приведены. Теоретический верхний сценарий 3–4 Uном не является гипотезой о среднем или случайным распределением, с которым можно автоматически сравнить выборочное среднее.

## Проверенные значения источника и пределы

Таблица P0054–P0074: n = 830; среднее 1,960; медиана 1,926; σ = 0,274; дисперсия 0,075; минимум 0,862; Q1 = 1,823; Q3 = 2,099; максимум 2,843. Контроль округления: 0,274² = 0,075076 согласуется с 0,075; Q3−Q1 = 0,276. Это проверка арифметики таблицы, не повтор статистики по исходным данным.

P0047 сообщает 95% не выше 2,45 Uном. P0048 отдельно сообщает менее 10% ниже 1,65 и 90% не выше 2,35. Из этих сведений нельзя получить точное утверждение аннотации/выводов «90% находятся **в диапазоне** 1,65–2,35»: нужна разность эмпирических CDF на двух границах. Если нижняя граница — 10-й процентиль, а верхняя — 90-й, центральная доля была бы около 80%, а не 90%. Не заменять 90 на 80 без исходной таблицы — принадлежность 1,65 к точному 10-му процентилю ещё не установлена.

Максимум 2,843 описывает максимум зарегистрированного поднабора. Он не исключает физически возможные 3–4 Uном, не оценивает вероятность таких режимов во всей сети и не обосновывает снижение испытательных уровней изоляции. P0047/P0089/P0091 содержат более широкие интерпретации о редкости/значимости; для диссертации их сузить до эмпирического наблюдения и явно назвать измерительные/выборочные ограничения.

Авторство — совместная работа Евдакова, Филатовой, Яблокова по титулу. Подробное распределение личных ролей — `unknown`; не придумывать его по порядку фамилий. Обе статьи ОЗЗ дополняют DATA-SD самостоятельным исследованием, не заменяя архитектурные части ФизКАН.
