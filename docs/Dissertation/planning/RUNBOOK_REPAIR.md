## R02 Восстановить карту переноса и замечаний

Повторяемая: один раздел или до 10 замечаний. Вход: реестры A, текущие TEX и неизменный DOCX.

1. Для каждого блока назначить файл и устойчивую метку/локатор; для технически поглощённого блока указать преобразование и целевой родительский объект. Не вставлять пустые абзацы только ради счётчика.
2. Для таблиц указывать строку/столбец и охват объединений; для рисунка — каждое размещение; для формулы — конкретное выражение и номер.
3. Для каждого замечания сравнить текст/автора/дату/ответы с сырыми частями OOXML, затем подтвердить исходный диапазон и новое место. Исходный статус Word и статус научного рассмотрения различать.
4. Проверить существование всех целевых путей/меток и обратную связь: от изменяемого подраздела можно получить его источники и замечания.
5. Выдать машинный список исключений; каждое исключение должно иметь основание, а не общий статус «учтено».

Выход: отдельная версия карт и протоколы R02-*; исходные сырые выгрузки не менять. DONE: все 2307 блоков и 144 замечания имеют проверяемое соответствие либо обоснованное техническое преобразование. Наличие ID в комментарии TEX недостаточно.
