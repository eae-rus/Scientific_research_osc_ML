1. Просканировать все XML-части пакета DISS-005 на наличие элементов ревизий Word (`w:ins`, `w:del`, `w:moveFrom`, `w:moveTo`, `w:rPrChange`, `w:pPrChange`, `w:tblPrChange`, `w:tcPrChange`, `w:sectPrChange`).

4. Проверить влияние правок на формулы, таблицы, поля и перекрёстные ссылки.
5. Сверить неизменность исходного baseline DOCX по SHA-256.
