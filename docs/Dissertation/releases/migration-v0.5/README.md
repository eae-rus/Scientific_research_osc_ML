## 2. Воспроизведение сборки (Инструкция)

Сборка осуществляется с помощью любого стандартного дистрибутива TeX Live или MiKTeX:

```bash
cd manuscript/
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

- Требуемый компилятор: `pdflatex` с поддержкой T2A (кириллица), UTF-8.
- Пакеты: `amsmath`, `amssymb`, `graphicx`, `tabularx`, `longtable`, `booktabs`, `caption`, `subcaption`, `hyperref`, `xcolor`, `enumitem`.
- Результирующий файл: `main.pdf` (132 страницы).
