# Чтение осциллограмм разных производителей

Единая точка входа — `osc_tools.io.oscillogram.load_oscillogram`.
COMTRADE читает существующая Python-библиотека проекта. Для остальных форматов
используются собственные декодеры APScilloscope, перенесённые в автономный адаптер
без закрытого пакета APS.Comtrade и без программ производителей.

## Форматы и границы поддержки

| Семейство | Вход | Особенности |
|---|---|---|
| COMTRADE | `.cfg/.dat`, `.cff` | Старый Python-парсер; можно передать CFG или DAT, регистр расширений пары не важен |
| ПАРМА | `.do`, `.d01`, `.d02`, … | Продолжения рядом с основным `.do`; открытие продолжения направляется на `.do` |
| ЭКРА DFR | `.dfr` | Части собираются по заголовкам, в том числе при переименовании |
| ЭКРА NDR | `DR…F0`–`DR…F3` с числовым расширением | Нужен соответствующий `WConfig.<номер>`; проверен `.046` |
| Бреслер | `.brs` | Структура 0107/v2; физические входы, как в пакетном экспорте WinBres |
| Чёрный ящик | `.bb` | KEBD 16/19/20, поток 6; исходные float-значения без квантования bb2cmt |
| НЕВА | `.os`, `.os1`, `.os2`, … | NEVA 3.0, кадровые и событийные записи |
| РЭС-3 | `.sg2` | SGN_FILE 6/256, один поток данных |

Суточные тренды ПАРМА `.to/.t0*` не являются осциллограммами и не включены.
АУРА не заявлена: в исследованном APScilloscope и наборе нет проверенного парсера
с образцами. Другие версии бинарных структур могут быть отклонены.
Расширение определяет читатель, но не гарантирует пригодность содержимого.

Отсутствующий `WConfig` — нехватка исходных данных. Он не восстанавливается по
догадке. Загрузчик сообщает `MissingCompanionError`, аудит отмечает
`missing_companion` и продолжает работу. `.017` без `WConfig.017` не проверен.

## Установка и использование

Из корня репозитория один раз соберите адаптер с .NET 8 SDK:

```powershell
dotnet publish tools/osc_formats/OscFormats.csproj -c Release -o build/osc_formats
```

Для чтения достаточно .NET 8 Runtime. Интернет, APScilloscope и NuGet-пакеты
во время чтения не нужны. COMTRADE не требует .NET вообще.
Для нестандартного расположения задайте `OSC_FORMATS_BRIDGE` или аргумент `bridge`
с путём к `OscFormats.dll`; рядом должны быть остальные файлы публикации.

```python
from osc_tools.io.oscillogram import load_oscillogram, iter_oscillograms

record = load_oscillogram("Осц. других производителей/путь/запись.brs")
df = record.to_dataframe()  # Polars: Time, аналоги, дискреты
print(record.cfg.sample_rates, record.analog_channel_ids)

record = load_oscillogram("путь/DR177F0.046", wconfig="путь/WConfig.046")

for path in iter_oscillograms("Осц. других производителей"):
    print(path)  # только входы осциллограмм, без DAT, WConfig и трендов
```

Без явного `wconfig` поиск идёт рядом с записью, без учёта регистра имени.
Конфигурации из других каталогов или чужих номеров терминалов автоматически
не подставляются. Части многотомных записей должны находиться рядом.

Возвращается `Comtrade` для COMTRADE либо `NativeOscillogram` для остальных типов.
Общий интерфейс: `time`, `analog`, `status`, `analog_channel_ids`,
`status_channel_ids`, `total_samples`, `frequency`, `cfg.sample_rates`,
`start_timestamp`, `trigger_timestamp`, `to_dataframe()`.
`ReadOscillogram().read_oscillogram(path, **options)` возвращает `(record, df)`.
Старый `ReadComtrade.read_comtrade(path)` также принимает нативные форматы и
сохраняет прежний контракт `(None, None)` при ошибке. Для диагностики и параметров
восстановления предпочтителен строгий `load_oscillogram`.

Время — секунды от начала записи; аналоги — float64 в единицах исходного канала;
дискреты — uint8 0/1. В `cfg.analog_channels` сохранены `uu`, `a`, `b`, `primary`,
`secondary`, `pors`, `ph`, `ccbm`. Аналоги **уже калиброваны**: A/B повторно
применять нельзя. Первичные и вторичные величины автоматически не смешиваются.
Имена каналов сохраняются, коллизии имён столбцов DataFrame получают суффиксы.
`NativeOscillogram` предоставляет данные для анализа, но не методы записи `Comtrade`.

Существующие сценарии формирования обучающих выборок, ищущие только `.cfg`,
сохраняют свой состав входных данных. Для новых наборов используйте новый обход.
Имена каналов производителей ещё нужно сопоставить исследовательским признакам:
универсальное чтение не назначает автоматически фазы, шины или целевые метки ML.
Обход исключает дубли CFG/DAT и ПАРМА DO/D01, однако DFR/NDR возвращает по частям:
разные входы могут давать одну собранную запись. Учитывайте это перед разделением
данных на train/test; не считайте количество входных файлов количеством событий.

## Повреждённые записи

По умолчанию неполные записи отклоняются. Только для НЕВА и РЭС-3 можно явно
разрешить отбрасывание последнего неполного блока:

```python
record = load_oscillogram("путь/запись.sg2", recover_incomplete=True)
```

Это выдаёт предупреждение и выставляет `record.recovery_requested=True`.
Флаг фиксирует запрошенный режим, а не доказательство усечения конкретного файла.
Повреждения внутри потока по-прежнему приводят к ошибке. Временная зона событийных
записей НЕВА следует локальной зоне процесса, как в исходном парсере; здесь
проверялось UTC+03:00. Для воспроизводимости не меняйте её между обработками.

## Проверка

На наборе «Осц. других производителей» 02.10.2026 проверено 282 входных файла:
98 Бреслер, 63 ПАРМА, 65 DFR, 13 BB, 9 НЕВА, 16 РЭС-3, 18 NDR.
При явном восстановлении успешно прочитан 281 вход, один `.017` не имеет WConfig.
Строгий режим отклоняет 7 оборванных НЕВА и 1 РЭС-3. Для 17 `.046` использован
WConfig.046 из независимого корпуса APScilloscope, переданный явно.
Исходные файлы не изменялись. Это проверка доступного набора, а не всех моделей устройств.

```powershell
python -m scripts.audit_oscillogram_formats "Осц. других производителей" --output reports/formats.json
python -m scripts.audit_oscillogram_formats "Осц. других производителей" --recover-incomplete --wconfig "путь/WConfig.046" --output reports/formats-recovery.json
python -m pytest tests/unit/test_oscillogram_formats.py
$env:APS_FORMAT_CORPUS = "../APScilloscope/Tests/ExternalFormats.Parity/Corpus"
python -m pytest tests/integration/test_native_oscillograms.py
```

Аудит записывает результат каждого файла и продолжает обработку после ошибок.
Код возврата 1 означает ошибку чтения; отсутствие компаньонов выделено отдельно.
Интеграционные тесты без `APS_FORMAT_CORPUS` пропускаются явно. С ним сравниваются
все отсчёты выбранных записей шести семейств с замороженными независимыми
экспортами, с учётом их квантования, кодировок и шкалы P/S; отдельно проверяются
DFR из разных частей и восстановление НЕВА/РЭС-3. Обычные unit-тесты проверяют
COMTRADE, выбор форматов, точность передачи float64, повреждение ответа адаптера
и коллизии имён. Происхождение исходников — в `tools/osc_formats/README.md`.
