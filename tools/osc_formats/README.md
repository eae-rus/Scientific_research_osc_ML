# Автономный адаптер форматов осциллограмм

Сборка из корня Scientific_research_osc_ML:

```powershell
dotnet publish tools/osc_formats/OscFormats.csproj -c Release -o build/osc_formats
```

Нужен .NET 8 SDK для сборки, .NET 8 Runtime для запуска. NuGet-зависимостей нет.
Парсеры не запускают WinBres, Etc, bb2cmt или другое ПО производителей.
Для переноса на другую машину копируйте весь каталог публикации, не одну DLL;
путь к DLL можно указать переменной `OSC_FORMATS_BRIDGE`.

`Readers/` — снимок `APScilloscope/Helpers/ExternalFormats` из локального checkout
APScilloscope с HEAD `4aad55c3f746c67d3b002c794f9e21e2d4b30086` (02.10.2026).
SHA-256 исходных файлов до адаптации сохранены в `Readers/upstream-sha256.json`.
Исходный проект: https://github.com/aps-m/APScilloscope . Его лицензионный текст
сохранён отдельно в `UPSTREAM-LICENSE.txt`; импортированные исходники не
перелицензируются лицензией Python-кода этого проекта.

Изменения снимка ограничены пространствами имён, видимостью классов и удалением
методов экспорта COMTRADE. Алгоритмы чтения, калибровки, проверки версий и объединения
частей сохранены. `Model.cs` — наша минимальная модель хранения, заменяющая типы
закрытой APS.Comtrade. Сам пакет APS.Comtrade и его код не требуются.

Для обновления снимка есть явный скрипт:

```powershell
python tools/osc_formats/import_readers.py ../APScilloscope
```

После обновления нужно проверить diff, обновить описание версии и лицензии,
пересобрать адаптер и выполнить тесты с эталонами и аудит исходного набора.
Парсер удаления экспортных методов рассчитан на текущую структуру исходников;
он не является универсальным преобразователем C#.

Внутренний протокол v1: `metadata.json` (UTF-8) и `samples.bin`: N временных
отсчётов float64 в секундах, затем A×N калиброванных аналоговых float64,
затем D×N дискретных uint8. Порядок каналов соответствует метаданным,
порядок байтов little-endian. Python проверяет размеры, конечность значений,
возрастание времени и диапазон дискретов. A/B сохраняются как метаданные и
не применяются повторно. Промежуточные файлы изолированы в TemporaryDirectory.
